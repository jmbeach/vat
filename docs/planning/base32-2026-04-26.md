# Plan: Crockford base32 utility (vat-q3m)

Implement the shared `base32` module backing every place VAT validates or generates an ID/prefix. See [LLD § ID alphabet & generation](../llds/backlog-format.md#id-alphabet--generation) and [specs FMT-B32-001..007](../specs/backlog-format-specs.md#crockford-base32-utility).

## Scope

In scope:
- `src/base32.rs` with `validate(s, expected_len)` and `random(n, &mut impl RngCore)`
- `Base32Error` enum (variants: `WrongLength`, `InvalidChar`)
- Cargo dependencies: `rand`, `thiserror`
- Unit tests for all seven specs

Out of scope (later backlog items):
- Wiring into `vat init` / `vat config set` (vat-q2e, vat-b6r)
- The 100-retry collision loop in `vat sync` (vat-s9g)
- The `[id]` marker parser (vat-g5y)

## Phases

### Phase 1 — Dependencies
- [ ] Add `rand = "0.8"` to `Cargo.toml`
- [ ] Add `thiserror = "1"` to `Cargo.toml`
- [ ] `cargo build` succeeds

### Phase 2 — Module skeleton
- [ ] Create `src/base32.rs` with `pub(crate)` `Base32Error` enum, `validate`, and `random` signatures
- [ ] Declare `mod base32;` in `src/main.rs`
- [ ] `cargo build` succeeds (functions can `unimplemented!()`)

### Phase 3 — Implementation
- [ ] Define the `ALPHABET: &[u8; 32]` table (lowercase canonical form)
- [ ] Implement `validate`: length check → per-char alphabet membership (case-insensitive)
  - [ ] Length mismatch returns `Base32Error::WrongLength { expected, got }` *(@spec FMT-B32-003)*
  - [ ] Invalid char returns `Base32Error::InvalidChar { ch, pos }` with `pos` as 0-based char index *(@spec FMT-B32-004)*
  - [ ] `I`, `L`, `O`, `U` (any case) are rejected, not folded *(@spec FMT-B32-005)*
- [ ] Implement `random`: draw `n` indices uniformly from `0..32` via the supplied RNG, map through `ALPHABET`, return `String` *(@spec FMT-B32-006, FMT-B32-007)*
- [ ] `cargo clippy --all-targets -- -D warnings` clean (project lints `clippy::pedantic = warn`; treat warnings as errors during this task)

### Phase 4 — Tests
- [ ] `validate` accepts mixed-case input *(@spec FMT-B32-002)*
- [ ] `validate` accepts every character in the canonical alphabet *(@spec FMT-B32-001)*
- [ ] `validate` rejects `I`, `L`, `O`, `U` in both cases with `InvalidChar` *(@spec FMT-B32-005)*
- [ ] `validate` rejects non-ASCII characters with correct 0-based char `pos` (e.g., `"a😀b"` reports pos=1) *(@spec FMT-B32-004)*
- [ ] `validate` returns `WrongLength` before checking characters (string of wrong length with all-invalid chars still reports `WrongLength`) *(@spec FMT-B32-003)*
- [ ] `random` with a seeded RNG produces a deterministic, asserted-exact output *(@spec FMT-B32-007)*
- [ ] `random` output contains only canonical-alphabet lowercase characters *(@spec FMT-B32-006)*

## Definition of Done

- All checkboxes above ticked
- `cargo build` and `cargo test` pass
- `cargo clippy --all-targets -- -D warnings` clean
- All seven `FMT-B32-*` specs flipped from `[ ]` to `[x]` in `docs/specs/backlog-format-specs.md`
- Code annotated with `// @spec FMT-B32-NNN` at function definitions

## Notes

- `rand 0.8` and `thiserror 1` are mature stable APIs; pinning to caret-major is fine.
- The seeded-RNG test should use `rand::rngs::StdRng::from_seed(...)` so the assertion stays stable across `rand` patch versions.
- `pos` is char index: compute via `s.chars().enumerate()`, not `s.bytes().enumerate()`.
